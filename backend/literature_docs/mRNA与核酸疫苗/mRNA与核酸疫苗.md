# mRNA 与核酸疫苗

> 来源：知识库内网整理 · 2026-08

## 什么是 mRNA 药物

**mRNA 药物 / 疫苗** 是利用人工设计的信使 RNA（mRNA），
递送入人体细胞后在**胞质中翻译成蛋白质**，从而：
- 表达**抗原**引发免疫（mRNA 疫苗）；
- 或表达**治疗性蛋白 / 酶**治疗疾病（蛋白替代、基因治疗）。

## 为什么 mRNA 能成药

1. **无需入核**：mRNA 只在胞质翻译，不整合进基因组，安全性相对可控。
2. **研发快**：序列只需编码目标蛋白，可快速迭代（新冠疫苗 1 年内获批）。
3. **平台化**：同一 LNP 递送配方可加载不同 mRNA（"换序列即换疫苗"）。

## mRNA 结构要素

| 元件 | 作用 |
|---|---|
| **5' cap (m7G)** | 保护 + 招募翻译起始因子 |
| **5' / 3' UTR** | 调控稳定性与翻译效率 |
| **开放阅读框 (ORF)** | 编码目标蛋白 |
| **3' poly(A) 尾** | 稳定性与翻译 |

## 化学修饰：降低免疫原性

- 用 **假尿苷（pseudouridine, Ψ）**、**N1-甲基假尿苷（m1Ψ）** 取代部分尿苷，
  显著降低先天免疫（TLR/RIG-I）识别，同时保持翻译效率。

## 递送：LNP（脂质纳米颗粒）

- **可电离脂质** + 磷脂 + 胆固醇 + PEG 脂质 组成的纳米颗粒，包载 mRNA。
- 静脉或肌肉注射后经内吞进入细胞，逃逸内涵体释放 mRNA。
- **代表**：Comirnaty（辉瑞/BioNTech）、Spikevax（Moderna）的新冠疫苗均采用 LNP-mRNA 平台。

## 代表应用

| 类别 | 代表 | 状态 |
|---|---|---|
| 预防性疫苗（新冠） | BNT162b2、mRNA-1273 | 已上市 |
| 癌症疫苗（个性化） | mRNA-4157（黑色素瘤，与 PD-1 联用） | 临床后期 |
| 蛋白替代 | mRNA-1647（CMV）、遗传代谢病 | 临床试验 |
| 治疗性抗体 | 体内生产单抗（"mRNA 表达抗体"） | 临床试验 |

## 挑战

1. **稳定性**：mRNA 易降解，需冷链与 LNP 保护。
2. **重复给药免疫反应**：对核酸载体/抗原的预先免疫。
3. **LNP 靶向性**：目前主要被动靶向肝脏 / 淋巴 / 肌肉，主动靶向仍在研发。
