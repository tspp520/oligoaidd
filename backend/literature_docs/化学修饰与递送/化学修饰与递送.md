# 小核酸药物的化学修饰与递送系统

> 来源：知识库内网整理 · 2026-08

## 为什么需要化学修饰

裸寡核苷酸在体内会：被核酸酶快速降解、免疫系统识别、半衰期极短、组织摄取差。
**化学修饰** 与 **递送系统** 是让核酸从"实验室分子"变成"可成药药物"的两大核心。

## 主要化学修饰

| 位置 | 修饰 | 作用 |
|---|---|---|
| **骨架** | 磷硫代（PS） | 抗核酸酶、促蛋白结合 |
| **骨架** | 吗啉（PMO）、肽核酸（PNA） | 高抗性、中性型 |
| **糖环 2'** | 2'-OMe | 提高亲和力与抗酶性 |
| **糖环 2'** | 2'-MOE | 稳定性佳、毒性低 |
| **糖环 2'** | 2'-F | 提高亲和力（siRNA 常用） |
| **双环** | LNA / BNA / cEt | 显著提高 Tm 与亲和力 |
| **末端/核碱基** | 假尿苷（Ψ/m1Ψ） | 降低免疫原性（mRNA 用） |

> 设计原则：**gapmer**（两端修饰、中间 DNA 缺口以激活 RNase H）常用于 ASO；
> **fully-modified**（全修饰）增稳；修饰同时要平衡毒性、亲和力与合成成本。

## 代表递送平台

### 1. GalNAc 偶联（肝脏主动靶向）
- **N-乙酰半乳糖胺** 偶联到寡核苷酸，与肝细胞 **ASGPR** 高亲和结合，实现肝靶向高效摄取。
- 皮下注射，剂量低，**一年两针**（如 Inclisiran）。
- 是当前**肝靶点** ASO/siRNA 的主流平台（Alnylam 的 "ESC-GalNAc"、Ionis/Akcea 等）。

### 2. LNP（脂质纳米颗粒）
- **可电离脂质** + 磷脂 + 胆固醇 + PEG 脂质，包载核酸（尤其 mRNA）。
- 静脉/肌肉注射，经内吞进入，内涵体逃逸释放。
- 代表：mRNA 疫苗、LNP-siRNA（Patisiran 早期平台）。

### 3. 其他
- **PDC（多肽偶联）**、抗体偶联、外泌体、聚合物胶束等肝外递送/靶向探索中。
- **中枢神经**：鞘内注射（IT）绕过血脑屏障（Spinraza、Huntington 项目）。

## 递送挑战与方向

1. **肝外靶向**：肌肉、肿瘤、免疫细胞等仍是难点。
2. **内涵体逃逸效率**：LNP 实际释放效率有限。
3. **重复给药反应**：预先免疫、补体激活相关假反应（CARPA）。
4. **长效化**：GalNAc + 高稳定修饰实现低频给药。
