# 小核酸药物概述

> 来源：知识库内网整理 · 2026-08
> 面向：OligoLab 平台·小核酸药物研发

## 什么是小核酸药物

**小核酸药物（Oligonucleotide Therapeutics）** 是一类以**寡核苷酸（十几到几十个核苷酸）** 为核心、
通过在基因转录 / 翻译 / 剪接层面调控疾病相关基因来实现治疗的新型药物。

与传统小分子（作用于蛋白）和抗体（作用于胞外靶点）不同，小核酸药物直接作用于**"上游的核酸"**，
理论上可靶向任意基因，甚至"不可成药（undruggable）"靶点，因此又被称为 **"从源头治病的药物"**。

## 主要类别

| 类别 | 中文 | 机制 | 代表药 |
|---|---|---|---|
| **ASO** | 反义寡核苷酸 | 与 mRNA 互补，诱导 RNase H 降解或空间位阻 | Nusinersen (Spinraza)、Eteplirsen |
| **siRNA** | 小干扰 RNA | 进入 RISC，针对 mRNA 降解 | Patisiran、Inclisiran (Leqvio) |
| **Aptamer** | 核酸适配体 | 高亲和结合靶蛋白（"化学抗体"） | Pegaptanib (Macugen) |
| **CpG/ 核酸佐剂** | 免疫调节剂 | 激活 TLR9 等免疫通路 | —（疫苗佐剂方向） |
| **mRNA** | 信使 RNA 药物/疫苗 | 在体内表达抗原或治疗蛋白 | Comirnaty、Spikevax |

> 狭义的"小核酸"常指 ASO / siRNA / 适配体；mRNA 因分子较大有时单列，此处一并纳入核酸药物范畴。

## 发展历程

- **1998**：第一个 ASO 药物 **Fomivirsen**（巨细胞病毒视网膜炎）获批，后退出市场。
- **2004**：**Pegaptanib** 作为首个适配体药物获批。
- **2013**：**Mipomersen**（ASO，家族性高胆固醇血症）在美获批。
- **2016**：**Eteplirsen**（DMD 外显子 51 跳跃）获批；**Nusinersen**（脊髓性肌萎缩症 SMA）获批。
- **2018**：**Patisiran**（首个 siRNA 药物，遗传性转甲状腺素蛋白淀粉样变性 hATTR）获批。
- **2020-2021**：**mRNA 新冠疫苗**（Comirnaty / Spikevax）获批，核酸药物进入主舞台。
- **2021**：**Inclisiran**（siRNA，长效降 LDL-C）获批，推动慢病"一年两针"模式。

## 行业意义与市场规模

- 小核酸药物弥补了小分子 / 抗体在**基因层面**的治疗空缺，尤其在**罕见病、遗传病**领域意义重大。
- 全球市场规模自 2020 年起快速扩张，多个 ASO/siRNA 药物年销售额超十亿美元（如 Spinraza）。
- **化学修饰（2'-OMe、LNA、PS 骨架）与递送（GalNAc、LNP）** 是让核酸药物成药的两大关键支柱。

## 研发中的关键科学问题

1. **序列设计**：如何设计高效、低脱靶的沉默序列（OligoFormer 等 AI 工具的作用点）。
2. **化学修饰**：提升稳定性、亲和力、降低免疫原性。
3. **递送系统**：肝脏（GalNAc）、肝脏以外组织、中枢神经（鞘内）等不同递送策略。
4. **脱靶与毒性**：种子区脱靶、免疫刺激、全身毒性评估。
